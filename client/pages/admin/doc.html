1. Project Overview

1.1 Introduction

The Hostel Management System is a comprehensive web-based application designed to streamline and automate the daily operations of hostel management. The system provides separate interfaces for administrators and students, enabling efficient management of rooms, attendance, complaints, leave requests, and fee payments.

1.2 Objectives

  • Digitize hostel management processes
  • Provide real-time tracking of student activities
  • Enable seamless communication between students and administration
  • Reduce manual paperwork and improve efficiency
  • Generate insightful reports for decision making

1.3 Scope

The system covers:

  • Student registration and profile management
  • Room allocation and tracking
  • Attendance monitoring
  • Complaint registration and resolution
  • Leave application and approval
  • Fee management and tracking
  • Report generation
  • Admin dashboard for overall control

8. Installation Guide

8.1 Prerequisites

  • Node.js (v14 or higher)
  • MongoDB (v4 or higher)
  • npm (v6 or higher)
  • Git

8.2 Backend Setup

# Clone the repository
git clone https://github.com/yourusername/hostel-management.git

# Navigate to backend directory
cd hostel-management/backend

# Install dependencies
npm install

# Create .env file
touch .env

# Add environment variables
echo "PORT=5000" >> .env
echo "MONGODB_URI=mongodb://localhost:27017/hostel_db" >> .env
echo "JWT_SECRET=your_secret_key" >> .env

# Start the server
npm start

8.3 Frontend Setup

# Navigate to frontend directory
cd ../client

# No build step needed - static files
# Serve using any static server
npx serve .
